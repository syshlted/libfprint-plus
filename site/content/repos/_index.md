# Repositories

Repositories will live under this site, one per distribution, release and architecture:

```
/repo/fedora/<release>/<arch>/
/repo/el/<release>/<arch>/
/repo/suse/<release>/<arch>/
```

Each holds the signed RPMs and signed repository metadata. A repository is listed here only once it exists and has been tested.

| Distribution | Releases | State |
|---|---|---|
| Fedora | 42 and newer, plus Rawhide and the branched release | Not published |
| RHEL / Rocky / AlmaLinux | 10 and newer | Not published |
| openSUSE / SLES | Leap and SLES 15 and newer, Tumbleweed | Not published |
